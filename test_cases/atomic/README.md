# Atomic Test Cases

Independent test cases that can be run in isolation. Each test is a single command or small sequence.

| File | TCs | Description |
|------|-----|-------------|
| [001-launch-and-session.md](001-launch-and-session.md) | TC-001~015 | Launch standalone, cargo debug, TUI, attach |
| [002-breakpoints.md](002-breakpoints.md) | TC-016~060 | Breakpoints by symbol, address, delete, dynamic |

## How to use

Pick a test case, copy the command, run in terminal.
